# Calculadora de calorías

Página que calcula el **IMC**, la **tasa metabólica basal** y las **calorías diarias recomendadas** según tu nivel de actividad.

**Ver online:** https://serberar.github.io/calculadora/

## Cómo calcula

1. **IMC** = peso (kg) / altura (m)².
2. **TMB** con la fórmula de Mifflin-St Jeor:
   - Hombres: `10 × peso + 6,25 × altura − 5 × edad + 5`
   - Mujeres: `10 × peso + 6,25 × altura − 5 × edad − 161`
3. **Calorías recomendadas** = TMB × factor de actividad (de 1,2 sedentario a 1,9 extremadamente activo).
